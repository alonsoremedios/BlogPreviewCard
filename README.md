## Tecnologías utilizadas

- HTML5 semántico
- CSS3 con unidades relativas (`rem`)
- Flexbox para alineación y centrado de la tarjeta
- Efectos de interacción con pseudo-clases (`:hover`)
- Sombras sólidas personalizadas con `box-shadow`
- Google Fonts (Figtree)
- Metodología BEM para clases

---

## Lo que aprendí

En este reto puse en práctica la maquetación de una tarjeta de artículo interactiva con estilo neo-brutalista (bordes negros y sombras marcadas):

- Creación de sombras sólidas sin difuminado usando `box-shadow: 10px 10px #000`.
- Control de estados dinámicos cambiando el color del título al pasar el cursor con `:hover`.
- Alineación del autor y su avatar mediante Flexbox con `display: flex` y `gap`.
- Control de anchos fluidos y responsivos combinando `width: 100%` con `max-width` para mantener la proporción en distintas pantallas.
